# WAV Player の要件

この文書は完成時の受け入れ条件を定める。現在動く範囲とビルド手順は [README](../README.md) に記載する。

## 対象と配布

- 製品名は WAV Player、実行ファイルは `wavplay.exe`。対象は Windows 11 25H2 以降の x64。 AVX2とMSVCの付随命令（BMI1/BMI2、LZCNT、MOVBE、FMA、F16C）、WindowsによるXMM/YMM状態の保存を必須とし、起動時に確認する。非対応時は理由を表示して終了し、SSEへの再生フォールバックは持たない。
- Visual Studio 2026 の `.sln` と `.vcxproj` で Debug/Release x64 をビルドする。安定版 MSVC、確定済み C++23 まで、静的 CRT（Debug は `/MTd`、Release は `/MT`）を使う。C++26 固有の機能は使わない。
- UI は Win32 の標準コントロールとシステムフォント。外部音声APIは Steinberg ASIO SDK。ビルドには MSBuild を使い、CMake は使わない。
- 自作ファイル（ソースコード、スクリプト、文書、設定・ビルド定義）を GPL-3.0-only で公開する。SDK、機器ドライバー、音源、実行ファイルは公開物に含めない。ビルドPCの `build.cmd` からReleaseビルド・ローカル再生用フォルダーの作成を行う。SDKの初回取得は `-FetchSdk` で明示する。生成されたフォルダーを再生PCへコピーして `setup.cmd` で機器と音源を設定する。再生PCにVisual StudioやSDKを必要とせず、設定後は停止状態で起動する。生成バイナリの再配布条件は[依存とライセンス](dependencies.md)で別に扱う。製品名には ASIO 商標を使わず、UI にロゴ、画像や独自テーマを用いない。

## 入力と出力の一致

| 項目 | 対応範囲 |
|---|---|
| コンテナー | RIFF/WAVE、RF64。64 ビットの位置・長さで 4 GiB を超えるデータを扱う |
| 入力形式 | PCM 16/24/32 bit、IEEE Float32、およびこれらの WAVE_FORMAT_EXTENSIBLE |
| Extensible PCM | 有効/格納ビット数は 16/16、24/24、24/32、32/32。未使用の下位ビットに 1 があれば拒否する |
| チャンネル | ステレオは左右の順を保つ。モノは左右に同じ値を出力する |
| レート（kHz） | 44.1、48、88.2、96、176.4、192、352.8、384 |
| ASIO 出力形式 | 整数 16/24/32 bit、32 bit 容器内の 16/18/20/24 bit、Float32/64。それぞれ LSB/MSB に対応する |

未知チャンク、任意のチャンク順、奇数長パディングを安全に扱う。必須チャンクの欠落・重複、サイズの矛盾、破損・切断、圧縮 WAV、Wave64、DSD、3 チャンネル以上は再生を拒否する。

ビットパーフェクトの保証範囲は、WAV のサンプル値から選択した ASIO 出力バッファーまでとする。形式全体で無損失に変換できる次の組み合わせだけを許す。音量調整、リサンプリング、ディザー、フェード、クロスフェード、エフェクトは行わない。

停止・再開時もサンプル値の保持を優先し、音声と無音の不連続によるクリックは仕様として許容する。クリック抑制のためのフェードやゼロクロス待ちは要求しない。一時停止から再開する際の未再生サンプルの欠落・重複、再生中の歪み、実装不具合による異音はこの許容に含めない。ユーザーの Stop では残りを打ち切り、次の Play で先頭から再生する。

| WAV 入力 | 許可する ASIO 出力 |
|---|---|
| PCM16 | 有効 16 bit 以上の整数、Float32/64 |
| PCM24（24/32 を含む） | 有効 24 bit 以上の整数、Float32/64 |
| PCM32 | 有効 32 bit の整数、Float64 |
| Float32 | Float32/64 |

## 設定したデバイスでの再生

- 使用する x64 ASIO ドライバーは `settings.ini` の `[General] SelectedDevice` に CLSID を手動指定する。起動時に指定したドライバーを初期化し、終了まで保持する。GUI に機器の一覧・選択・変更操作を設けず、起動引数でも機器を変更しない。未設定（キー不在・空欄・ゼロ GUID）では `NO DEVICE` と設定案内を表示し、Play を無効にする。不正な CLSID、登録の欠落、初期化失敗も理由を表示して再生を拒否する。別の機器への代替は行わない。
- 出力は機器別の `OutputPair` に隣接ペア（1/2、3/4、…）の先頭番号を手動指定する。未設定は1。1始まりの奇数だけを受け付け、存在しないペアでは再生を拒否する。機器・出力ペアの変更は次回起動から適用し、GUI では設定値を表示する。
- 再生前に WAV のレートへ合わせる。ドライバーが拒否すれば停止する。変更したレートは再初期化・終了時に元の値への復元を試みる。
- reset・buffer-size-change 通知では停止して同じドライバーを再初期化する。起動時の機器別設定を保持し、再開にはユーザー操作が必要。
- `settings.ini` の `BufferSize` は手動編集し、次回起動から適用する。未設定または 0 は、バッファーを作成する際に現在のレートで照会したドライバー推奨値を使う。起動時の推奨幅や工場出荷値へ固定する指定ではない。正の値は現在の範囲・粒度を検証して、そのフレーム数を使う。無効値または設定拒否では再生を開始せず、別の幅へ代替しない。GUI に実値、最小・推奨・最大、粒度、現在のレートでのブロック時間を表示する。ASIO コントロールパネルの起動機能は設けない。
- Buffer表示は要求設定・照会済みの能力・検証済みの確保値を区別する。幅の検証や確保に失敗しても、その要求で確認できたレートと能力は表示する。未照会・照会失敗・矛盾した能力から実値やブロック時間を作らない。停止後は最後の確保値と明示して記録を保持し、次のPlayと再初期化では古い能力・確保情報を消す。長い機器名でもOutputが隠れず、最小ウィンドウでもBufferの全情報を読めるようにする。
- 推奨バッファー幅は終了・再初期化時に自動復元しない。通常の停止・バッファー破棄・ドライバー解放は行い、推奨幅を戻すための追加のバッファー作成やストリーム開始は行わない。ドライバーが指定幅を推奨値として保持する場合、以後の本製品の `BufferSize=0`／未設定や、同じドライバーの推奨値を使う後続アプリの幅・遅延に影響し得る。推奨幅の保持・変更はドライバーに依存し、終了前後の差だけを終了失敗とはしない。変更したサンプルレートの復元方針は上記のとおりとする。
- `settings.ini` の機器別 `StartSilence` は、ストリームの開始時（再生開始・再開・異レートの曲間）に最初の音声より前に流す無音の長さ（ミリ秒）。機器が開始直後の出力を欠かす時間に合わせる。手動編集し、次回起動から適用する。未設定は 100、範囲は 0～1000 の整数。ブロック単位に切り上げる。無効値では再生を開始しない。同一レートの曲間には入れない。
- 一時停止は ASIO の stop を使って位置を保持し、再開前にバッファーを充填する。アンダーラン時は直ちに停止へ移り、無音を挿入して再生を継続しない。

## プレイリストと操作

- 実行ファイルの隣の `playlist.txt` を起動時に一度読む。UTF-8（BOM 任意）で 1 行 1 絶対パス。不正な UTF-8 はリスト全体の読み込みエラーとする。
- 行末の CR/LF だけを取り除き、他の空白を保存する。空行と先頭が `#` の行を無視し、順序と重複を維持する。ローカルボリュームのファイルのみ受理する。UNC・ネットワークドライブ、存在しないファイル、解析不能なファイルは除外し、その件数を示す。
- リストにはフルパスを表示する。起動時は停止。クリックで選択、ダブルクリック・Enter で選択曲を再生する。Play/Pause または Space で再生・一時停止、未選択からの再生は先頭曲。Stop または Escape で再生を打ち切って位置を0に戻し、選択曲は保持する。一時停止中・曲末でも Stop で位置を0に戻し、次の Play は選択曲の先頭から始める。
- 同一レートで現在の出力に無損失変換できる次曲へはサンプルの欠落・重複・無音挿入なくつなぐ。レート変更に必要な曲間の無音は許す。リストにある次曲が選択中の機器で再生不能なら、その項目を選択して停止する。最終曲の後は停止する。
- ウィンドウには Device、Output、Buffer、リスト、Play/Pause、Stop、経過/総時間、状態を簡潔な英語で示す。リサイズにリストを追従させ、位置・サイズを保存する。Unicode と長いパスに対応する。リピート、シャッフル、リスト編集、シーク、手動の次/前送りは対象外。
- 経過/総時間は曲ごとに秒単位で表示する。再生中は現在再生している曲を対象とし、別の行を選択しただけでは表示対象を変えない。停止中は選択曲を示す。経過は提出済みの有効PCMフレーム数に基づき、開始無音では進めず、Pauseで保持し、Stopで0となる。自然終端では再生を終えた曲を選択して総時間を示す。曲の切替ではその曲の位置・長さ・レートを使う。表示は `Time: m:ss / m:ss`、1時間以上は `h:mm:ss`、未取得時は `Time: --:-- / --:--` とする。物理DACの聴取位置は推測しない。
- 同一ユーザー・同一Windowsログオンセッション内では、設置場所によらず1つだけ起動する。後発起動は機器を初期化する前に既存ウィンドウを検出し、最小化されていれば復元して前面化を要求し、正常終了する。Windowsが前面化を制限した場合はタスクバーで通知する。後発起動の引数・設定・リストを既存の再生へ適用せず、自動再生もしない。先行GUIの準備は期限を設けて待ち、既存プロセスが応答しないことを理由に二重起動しない。終了・異常終了後は再び起動できる。

## 設定と診断

実行ファイルの隣の `settings.ini` は UTF-8（BOM 任意）、最大1 MiB、NULなし。作業ディレクトリによらず同じファイルを使う。起動時に一度読み、機器・機器別設定・ウィンドウ状態を適用する。ASCII のセクション名・キー名・CLSID は大小を区別せず、空白、CRLF/LF、`;` と `#` によるコメントを受け付ける。既知キーの重複、不正 UTF-8、既知値の不正・範囲外、読み取り失敗は設定エラーとして表示して再生を開始しない。未知キーと選択していない機器の値は保持し、再生設定に使わない。

`SelectedDevice` と機器別設定は手動編集する。`Name` は任意の Unicode 表示名で、未指定なら CLSID を表示する。`OutputPair` はペアの先頭の1始まりのチャンネル番号、`BufferSize` はフレーム数、`StartSilence` はミリ秒。数値は10進整数で、機器別数値に符号や小数は使わない。[設定例](../settings.example.ini)を実行ファイルの隣へ `settings.ini` としてコピーできる。

```ini
[General]
SelectedDevice={ASIO-driver-CLSID}

[Device.{ASIO-driver-CLSID}]
Name=Device name
OutputPair=1
BufferSize=0
StartSilence=100

[Window]
X=100
Y=100
Width=900
Height=600
Maximized=0
```

`Window` の `X`・`Y`・`Width`・`Height` は通常表示時の外枠の矩形を、物理ピクセル・スクリーン座標で保存する。位置は負の値を受け付け、幅・高さは正の値を必要とする。Windowの既知項目をすべて省略すると標準配置。既知項目を1つでも指定する場合は矩形の4キーを必須とし、一部だけの指定や `Maximized` だけの指定は設定エラーとする。`Maximized` は0/1で、このキーだけは省略でき、省略時は0。復元時は現在のモニターの作業領域と GUI の最小寸法に合わせて矩形を補正し、画面外や極端な寸法で操作不能にしない。最小化状態は保存せず、通常矩形と最大化への復帰状態を保持する。

起動時の読み取りに成功した場合は、終了時にウィンドウ状態を保存する。未設定機器での終了も保存対象とする。保存直前の最新ファイルを読み、`Window` の既知キーだけを更新して、`SelectedDevice`・機器別設定・未知キー・他機器・コメント・BOM を保持する。起動後の手動編集も失わず、その再読を再生設定へ適用しない。実行ファイルの隣の一時ファイルへ書き込み、フラッシュの成功後に置換する。失敗時は既存ファイルを壊さず、機器を解放した後にエラーを表示して非ゼロで終了する。起動時の設定エラーでは自動保存しない。

## 再生経路と検証

専用の読み込みスレッドで `CreateFileW` と同期・キャッシュ付きの逐次 `ReadFile` を使う。曲全体をメモリに置かず、出力形式への変換・モノ複製と次曲の先読みを行う。左右の変換済みデータを固定容量の単一生産者・単一消費者（SPSC）リングで渡す。ページ単位に確保する領域は 16 MiB 以下、目標は約 2 秒。管理領域とステレオブロックをキャッシュライン境界に整列させ、開始前に全ページに触れる。片側32バイト以下の左右は同じ64バイトラインの前半・後半を使い、同時に所有・公開する。異なるブロックは同じラインへ詰めず、大きいチャンネルは従来どおり別々の整列した平面へ置く。

通常のコールバックは準備済みデータのコピー、ロックフリーなカウンター更新、必要な閾値での通知に限定する。メモリ確保、ロック、ディスク I/O、ログ、GUI 操作を行わない。停止・再初期化は制御スレッドに依頼する。アプリのスレッドは MMCSS に登録せず、ドライバーのスレッド優先度・アフィニティを変更しない。再生中だけシステムの自動スリープを抑止し、画面の消灯を妨げない。

外部フレームワーク不要のコンソールテストとプロジェクト所有の模擬 ASIO で、ドライバーの登録なしに試験できるようにする。ビルド・テスト・静的解析・AddressSanitizer・成果物監査をローカルと GitHub Actions で実行する。CIから実行物を配布しない。実機はx64 ASIOドライバーが提示するレート・出力型・バッファー範囲に基づいて確認し、特定の機種名で製品の挙動を分岐しない。合否の判定方法は [試験仕様](test-specification.md) に記す。
